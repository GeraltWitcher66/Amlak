# کیانی املاک — وب‌سایت املاک ساحلی آنتالیا و آلانیا

سایت معرفی و فروش املاک ساحلی ترکیه با بک‌اند PHP و دیتابیس SQLite؛ شامل صفحات عمومی
(صفحه اصلی، فهرست املاک با فیلتر، جزئیات ملک، فرم درخواست مشاوره) و یک پنل مدیریت
برای املاک، درخواست‌ها و محتوای سایت.

## پیش‌نیازها

- PHP نسخه ۸.۱ یا بالاتر با افزونه‌های `pdo_sqlite` و `sqlite3`
- Node.js (فقط برای اجرای تست دودی؛ اختیاری)

بدون Composer و بدون وابستگی خارجی کار می‌کند.

## راه‌اندازی

```bash
# ۱) ساخت دیتابیس و داده اولیه (ایمن برای اجرای چندباره)
php seed.php

# برای ساخت دوباره از صفر:
php seed.php --fresh

# ۲) اجرای سرور توسعه
php -S 127.0.0.1:8088 -t .
```

سپس <http://127.0.0.1:8088/index.php> را باز کنید.

### ورود به پنل مدیریت

<http://127.0.0.1:8088/login.php>

- نام کاربری پیش‌فرض: `admin`
- رمز عبور پیش‌فرض: `admin123`

> **مهم:** پیش از انتشار روی اینترنت، رمز پیش‌فرض را تغییر دهید:
> `php seed.php --fresh --password=رمز-جدید`
> و در `includes/init.php` مقدار `secure` کوکی نشست را برای HTTPS فعال کنید.

## تست دودی

سرور توسعه باید از قبل بالا باشد:

```bash
node tests/smoke.mjs
```

متغیر `BASE` برای تغییر آدرس سرور قابل استفاده است:
`BASE=http://127.0.0.1:8088 node tests/smoke.mjs`

## ساختار پروژه

```
index.php                 صفحه اصلی
properties.php            فهرست املاک + فیلتر و مرتب‌سازی
property.php              جزئیات ملک
leads.php                 دریافت فرم درخواست مشاوره
login.php / logout.php    ورود و خروج مدیر
admin.php                 پنل مدیریت (املاک، درخواست‌ها، محتوا)
schema.sql                اسکیمای دیتابیس
seed.php                  ساخت دیتابیس و درج داده اولیه
seed-data.json            داده اولیه املاک، مشاور و نظرات
includes/                 هسته مشترک، هدر و فوتر
assets/css/style.css      استایل سایت
assets/js/app.js          رفتارهای رابط کاربری
storage/                  دیتابیس SQLite (در گیت نیست)
tests/smoke.mjs           تست دودی صفحات و فرم‌ها
docs/                     مستندات امکانات سایت
```

## نکات استقرار

- دیتابیس در `storage/kiani.sqlite` ساخته می‌شود؛ این پوشه باید برای وب‌سرور قابل نوشتن باشد.
- پوشه `storage/` نباید از طریق وب قابل دسترسی باشد؛ در Apache/Nginx مسیر آن را مسدود کنید.
- فایل `includes/init.php` مسیر دیتابیس و حساب پیش‌فرض مدیر را تعریف می‌کند.
